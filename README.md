# Relax Space 🌊

> 音・呼吸・映像で、数分間だけ頭を手放す場所。

**デモ → [junia2009.github.io/relax_space](https://junia2009.github.io/relax_space/)**

---

## どんなアプリ？

スマートフォンのブラウザで開くだけで使える、瞑想・リラックス用の Web アプリです。  
インストール不要で PWA（アプリとしてホーム画面に追加）にも対応しています。

5 つのテーマと呼吸ガイド、タイマーを組み合わせて、自分好みのリラックスタイムを作れます。  
テーマは 3D カルーセルで横スワイプして選択。セッションを重ねると実績バッジが解除されていきます。

## こだわりポイント

### 1. Three.js で本格的な 3D シーンを構築

ブラウザ上で WebGL を動かし、テーマごとにまったく異なる世界を実装しました。

- **パーティクルシステム** を自作し、プランクトン・蛍・星・火の粉をそれぞれ専用のロジックで動かしています
- **ポイントライト** の強度を時間に合わせてアニメーションさせ、焚き火のちらつきや深海の光のゆらぎを表現
- **フォグ（霧）** を加えることで奥行き感と幻想的な雰囲気を演出

```js
// 焚き火ライトのちらつき（2 つの sin 波を重ねてランダム感を出す）
fireLight.intensity = 5.5 + Math.sin(t * 9) * 0.8 + Math.sin(t * 14.3) * 0.5;
```

### 2. 「星が消えるバグ」を根本から修正

開発中に **宇宙モードで数分後に星が消える** 問題を発見しました。

**原因の特定**：星フィールド全体を `rotation.y = t * 0.008` で回転させていたため、約 6.5 分後（π ÷ 0.008 秒）に 180° 回転してカメラの背後に全星が回り込み、見えなくなっていました。

**修正**：回転方式を廃止し、各星が Z 軸方向にカメラへ向かって流れ続け、通り過ぎたら奥にリセットされる**スターストリーミング方式**に変更。どんな長さのセッションでも星が途切れません。

```js
// 各星を個別に Z 方向へ移動させ、カメラを通過したらリスポーン
updaters.push(t => {
  for (let i = 0; i < SC; i++) {
    sArr[i * 3 + 2] += sSpeeds[i];       // Z 方向に流す
    if (sArr[i * 3 + 2] > 18) resetStar(i); // カメラ通過 → 奥にリセット
  }
  sGeo.attributes.position.needsUpdate = true;
});
```

### 3. iPhone / Safari の細かい差異への対応

iOS Safari は Chrome と挙動が異なる箇所が多く、以下を丁寧に対応しました。

- **`100dvh`（Dynamic Viewport Height）**: ブラウザの UI バーが表示/非表示になっても画面がずれない
- **`env(safe-area-inset-*)`**: ノッチやホームバーに UI が隠れないよう余白を動的に確保
- **`viewport-fit=cover`**: 画面の端まで背景色を広げ、没入感を高める
- **`-webkit-backdrop-filter`**: Safari でブラーエフェクトを有効化
- **`color-mix()` 非対応への回避**: CSS 変数 `--theme-glow` で代替し、全ブラウザ対応

## 音の設計

すべてのテーマの音を、録音素材を使わずに、研究で報告された音響特性や物理法則からリアルタイムに合成しています（`src/sound/`）。

### 共通の方針

- **「音の出来事」として鳴らす** : 定常的な広帯域ノイズは脳に「ノイズ」として認識されやすいため、波・気泡・虫の声・パチパチのように時間的に変化する出来事として合成します（胎内音のみ、途切れず続くこと自体が安心材料なので連続再生）
- **耳に刺さる帯域を避ける** : 人の耳が最も敏感な 3–4 kHz 帯（外耳道の共鳴）にエネルギーを集めません
- **自然音の効果** : 自然音はストレス・心拍・血圧・気分を改善し、なかでも水の音は気分の改善、鳥など生き物の声はストレスの軽減に効果が大きい（Buxton et al. 2021, *PNAS* のメタ分析）
- **純正律ドローン** : 整数比の倍音列はうなりが最小で、静かな土台になります
- **バイノーラルビート** : 左右の耳にわずかに違う周波数を聞かせる手法。不安・痛み・注意への効果はメタ分析で中程度（g = 0.45; Garcia-Argibay et al. 2019）。ヘッドホン使用時のみ成立するので、土台として控えめに鳴らします

### 🌊 深海 — 海の中で聞こえる音

テーマは「海の底」なので、浜辺の波音ではなく水中の音場にしています。

| 音 | 合成方法 | 根拠 |
|----|----------|------|
| 頭上で砕ける波 | 10–14 秒周期で、低いうねりと気泡の群れ（半径 1.5–6 mm）が訪れる | うねりの周期 10–16 秒。水中の砕波音は 500–2000 Hz に山（1 kHz で最大）、2 kHz 以上は約 −10 dB/oct（Deane 1997） |
| 気泡 | 気泡ひとつひとつを固有振動数の減衰音として鳴らす | Minnaert 共鳴: f ≈ 3.26 / 半径[m]（半径 3 mm → 約 1 kHz） |
| 昇っていく泡 | ときどき近くを「ポコポコ」と大きめの泡（約 330–650 Hz）が昇る | 同上 |
| 遠いクジラの歌 | まれに、低くうなる 2–4 音のフレーズ（120–340 Hz）。距離で倍音が落ちる | ザトウクジラの歌の単位は基本周波数 30 Hz–5 kHz、大半が 3 kHz 未満 |
| 水中の空間 | 高域を緩やかに減衰させ、長い残響を付ける | 深いほど高域が吸収される |

### 🌿 森 — 夜の森

テーマは「夜の森」（映像は蛍）なので、昼の小鳥ではなく夜の音にしています。

| 音 | 合成方法 | 根拠 |
|----|----------|------|
| カンタンの合唱 | 約 2 kHz の純音のパルス列。3 匹が鳴いては休み、鳴くタイミングが少しずつそろっていく | カンタンは約 2 kHz で鳴く虫の中で最も低く、スズムシ（3.2–4.5 kHz）のように耳に刺さらない |
| 鳴く速さ | 気温 20 °C を想定して毎分 110 回 | Dolbear の法則（1897）: T[°C] = 10 + (毎分の回数 − 40) / 7 |
| フクロウ | まれに低い声で「ホッホ … ゴロスケ ホッホ」 | 日本のフクロウの代表的な鳴き方 |
| 遠くのせせらぎ | 小さな気泡の音（平均 18 個/秒）の集まり。ノイズではなく粒の集合として鳴らす | 流れの音の正体は気泡の振動（Minnaert 共鳴）。水の音は気分の改善効果が最大（Buxton 2021） |
| 葉擦れ | ときどき吹いて止む風 | — |

### ✨ 宇宙 — 宇宙を伝わる電波の音

真空に音はありませんが、宇宙空間を伝わる電波には耳で聞ける周波数のものがあり、実際に録音されています。

| 音 | 合成方法 | 根拠 |
|----|----------|------|
| ホイッスラー | 「ヒューー」と下がる純音。高い周波数ほど先に届く | 雷の電磁パルスが地球磁場に沿って伝わる間に分散する。到達の遅れは Eckersley の法則 t = D / √f |
| エコー | ときどき、南北半球を往復したエコーが分散 2D・3D でさらに間延びして届く | 同上。本物は 1–10 kHz だが、耳に刺さらないよう 2.4 kHz–500 Hz で鳴らす |
| 土台 | 40 Hz 基音の純正律ドローンと、極めて遅い揺らぎ（ノイズなし） | — |

### 🔥 焚き火

| 音 | 合成方法 | 根拠 |
|----|----------|------|
| パチパチ | 大きさがべき乗分布に従い、小さなパチが大半で大きなパチッはまれ。大きいほど低く長い | クラックリングノイズのべき乗則（Sethna, Dahmen & Myers 2001, *Nature*） |
| 群発 | 一度はじけると続けてはじけやすい（自己励起型の点過程 = Hawkes 過程） | 同上 |
| 燃え上がり | ときどき低い炎の音が膨らみ、約 2.1 Hz で揺れる | 炎のパフィング周波数 f = 1.5 / √直径（Cetegen & Ahmed 1993）。直径 50 cm → 約 2.1 Hz |
| 薪が崩れる | まれに鈍い「ゴトッ」の後、小さな火の粉がはぜる | — |

### 検証（各テーマ 60 秒をオフラインで描画して解析）

A 特性（人の耳の感度）で重み付けした音量と、帯域ごとの割合です。

| テーマ | 全体 | 土台（ドローン等） | 音の出来事 | 3–4 kHz の割合 |
|--------|------|--------------------|------------|----------------|
| 🌊 深海 | −49 dBA | −58 dBA | −50 dBA | 0 % |
| 🌿 森 | −50 dBA | −60 dBA | −50 dBA | 0 % |
| ✨ 宇宙 | −50 dBA | −52 dBA | −55 dBA | 0 % |
| 🔥 焚き火 | −52 dBA | −59 dBA | −52 dBA | 0.3 % |

（dBA はデジタルフルスケール基準の相対値）テーマ間の音量差は 3 dB 以内にそろえ、音の出来事が土台より前に聞こえるように調整しています。

## 胎内音テーマについて

録音素材は使わず、胎内音の研究で報告されている音響特性を、母体の生理学的なパラメータからリアルタイムに合成しています（`src/sound/womb.js`）。

### 音の構成と根拠

| 成分 | 合成方法 | 根拠 |
|------|----------|------|
| 母体大動脈音（主役） | 拍ごとに脈打つ低い「ゴォッ」（< 160 Hz）。拡張期の流れが小さく拍動が強い | 胎内音の鎮静効果は母体大動脈音が主体（室岡 1974, 1979） |
| 子宮動脈の血管雑音 | 200–800 Hz の「ザッ」。妊娠子宮の動脈は抵抗が低い（RI ≈ 0.5）ので拡張期にも途切れず、流速が上がると音の重心も上がる | Riknagel et al. 2017 |
| 背景の低周波ノイズ | 100 Hz 未満の連続ノイズ。母体の呼吸（15 回/分）に合わせてゆっくり膨らむ | Walker et al. 1971; Querleu et al. 1988 |
| 母体心音 S1/S2 | 25–100 Hz の減衰振動。S2 は大動脈弁（A2）→肺動脈弁（P2）の 2 成分で、吸気で分裂が広がる | Riknagel et al. 2017 |
| 腸音 | 不規則な間隔（ポアソン過程、平均 18 秒）で鳴る小さな気泡音のかたまり | Querleu et al. 1988; Parga et al. 2018 |
| 母体組織のフィルタ | 全体を 4 次ローパス（450 Hz）に通し、125 Hz 付近を +3.7 dB。1 kHz で約 −28 dB | Gerhardt & Abrams 2000 |

### 心拍のタイミング

- **心拍数** : 80 bpm（妊娠後期は非妊娠時より 10–20 bpm 高い）
- **呼吸性の揺らぎ** : 吸気で ±3 bpm 速くなる（呼吸性洞性不整脈）＋拍ごとに約 1% のランダムな揺らぎ
- **S1→S2 の間隔** : 等容性収縮時間 45 ms ＋ 左室駆出時間（418 − 1.6 × 心拍数）ms（Weissler 1968）
- **血流音の遅れ** : 心臓から子宮動脈まで約 0.55 m ÷ 脈波伝播速度 6.6 m/s ≈ 85 ms 遅れて「ザッ」が届く

### 検証（30 秒をオフラインで描画して解析）

| 帯域 | 合成音（20–100 Hz 比） | 文献値（Querleu 1988） |
|------|------------------------|------------------------|
| 20–100 Hz | 0 dB | 60–85 dB（最大成分） |
| 100–500 Hz | −8 〜 −15 dB | 60 dB 未満 |
| 500–1000 Hz | 約 −39 dB | 約 40 dB |

拍の周期は 0.76 秒（≈ 79 bpm）で、設定どおり脈打っていることを確認しています。

### 実用上の工夫

- **小型スピーカー対応** : 胎内音の中心である 100 Hz 未満はスマホのスピーカーではほとんど鳴りません。
  そこで低音から倍音（100–300 Hz）を作り、脳に基音を補ってもらう「仮想低音」を加えています（missing fundamental 現象）
- **映像との同期** : 画面の光は、実際に鳴っている大動脈音の拍に合わせて脈打ちます
- **赤ちゃんへの配慮** : バイノーラルビートは使わず、タイマー終了時はベルを鳴らさずに 30 秒かけて静かに消えます

> **音量の注意** : 市販の乳児用スリープマシン 14 機種を調べた研究では、最大音量だと 30 cm の距離で全機種が新生児室の推奨上限 50 dBA を超えていました（Hugh et al., *Pediatrics* 2014）。
> スマホは赤ちゃんから離して（1 m 以上）置き、音量は控えめにしてください。
